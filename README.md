There are 3 Notebooks for this file. Here is the order to run them in:
1. data_wrangling (creates the training data)
2. model_training_m (trains men's models)
3. model_training_w (trains women's models)

Not all of the data was able to be uploaded to Gradescope because some of the files were too large. Data in the data_2026 folder can be downloaded from https://www.kaggle.com/competitions/march-machine-learning-mania-2026/data. Files 2 and 3 should be able to run without the downloaded data from Kaggle. File 1 needs the MMasseyOrdinals.csv file.
